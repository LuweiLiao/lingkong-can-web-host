# 瓴控 CAN 关节电机 Web 上位机

基于《上海瓴控 / 苏州控越 CAN 通信协议 V2.4》的浏览器上位机。通过 SLCAN USB 适配器（Web Serial）直接连接电机，无需安装后端。

## 使用

1. 用 Chrome、Edge 或 ego lite 打开 `index.html`（双击即可；如浏览器限制本地文件访问串口，可在本目录运行 `python -m http.server 8000` 后访问 `http://localhost:8000`）。
2. 第一次点"添加串口…"授权 SLCAN 适配器，之后在串口下拉框里直接选择。
3. 选 CAN 速率（默认 1M）和节点 ID（默认 1），点"连接"。连接后自动读取减速比、相电流比例、电机参数和运行时 PID；电机处于开启状态时自动开始采集曲线。

## 功能

- **顶栏**：连接设置、状态灯与故障、多圈/单圈角度、速度、Iq、母线电压电流、温度、编码器位置；常驻"停止""关闭电机"。
- **电机控制**：开启/停止/关闭、清除故障、抱闸，A1~A8 八种运动模式，连续发送。
- **零点与角度**：多圈角度拆成"输出端圈数 + 单圈"、输出端角度（÷R）、编码器对应角度；设零点（0x95，RAM）、清多圈（0x93）、零偏写 Flash（0x19）。
- **PID 调参**：运行时 PID 与限制（0xC0/0xC1），Kp/Ki 写入参数表并保存；阶跃/方波/正弦响应测试，阶跃给出上升时间、超调、调节时间、稳态误差。
- **电机参数**：运动限制、转向、保护等级与阈值、泄放电阻与抱闸、通信配置，图形控件编辑，"应用"写 RAM、"保存"写 Flash，可导入导出 JSON。
- **曲线**：角度、速度、电流、母线电压、母线电流、编码器位置 6 个子图；滚轮缩放时间轴（联动）、Ctrl+滚轮缩放纵轴、拖动平移、双击复位；导出 CSV / PNG。
- **维护工具**（弹窗）：编码器读数、0x18/0x1B/0x20 校准、重启、恢复默认、广播控制。
- **帧监视**：收发记录与解析、手动发送原始帧。

## 角度说明

协议中普通命令和读数的角度都是**电机侧**。减速比 R 由参数 0x00BE/0x00BF 读出：单圈范围 0 ~ 360×R；多圈角度 = 输出端圈数 × 360R + 单圈；编码器 0~65535 对应单圈范围；输出端角度 = 电机侧 ÷ R。

## 安全

首次调试请空载、固定电机并准备独立断电，通信命令不能替代急停。校准、恢复默认、写 Flash 等高风险命令需输入确认词；0x4A 默认锁定。

## 目录与测试

```
index.html          页面
css/style.css       样式
js/slcan.js         SLCAN 串口驱动（一问一答排队、匹配、超时）
js/protocol.js      协议编解码
js/params.js        参数表（附录 A/B/C）
js/scope.js         示波器（Canvas，缩放平移）
js/app.js           连接、轮询、电机控制、零点
js/panel-*.js       曲线、参数、PID、维护、帧监视
test/               单元测试、模拟串口设备与端到端测试
```

```
node test/protocol-test.js   # 用协议文档示例帧核对编解码
node test/slcan-test.js      # 用模拟设备测 SLCAN 驱动
node test/check-ids.js       # 检查脚本引用的元素 id 是否都存在
```

端到端测试：把 `test/mock-serial.js` 和某个 `test/*-e2e.js` 注入 `index.html`，用无头 Edge/Chrome `--dump-dom` 运行，结果写在页面的 `#e2e` 元素里。
